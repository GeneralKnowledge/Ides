# Historical Anchors — Continuity Bible

Events that **must not** be casually altered. Fiction orbits them; it does not relocate them.

**Variation key:**
- **Acceptable:** texture, private motives, unrecorded conversations, minor timing flex (± days) for undocumented side-events
- **Unacceptable:** changing outcome, place, primary participants, or public political meaning

## Anchor test for any plot pitch

1. Does it require moving an A-event’s date/place/outcome? → **Reject** or redesign.
2. Does it require a major historical figure to know the future? → **Reject**.
3. Does it fill silence without contradicting A/B? → **Allowed** (log in `canon.md`).
4. Does it pick one side of a C-conflict? → **Allowed only if logged** as fictional canon, not as “history.”
