**Goal:** Human cold read feels less synthetic. **Not** detector score-chasing.

## Held (do not break)

- Soft-chain dinner opening; Cassius POV; Sextilius climber
- Host soft-chain line; Cassius “I digest.”
- Petitioner mis-ask → servant jug → smaller ask ignored
- Queen/child/Transtiberim as rumour only
- Street exit: laugh-on-cue / silence attached to land
- No em dashes; no plot/POV change

---

## Craft moves used (feel, not metrics)

| Cut / softened | Why it read synthetic |
|----------------|------------------------|
| “as if mercy were a spice that made leftover Pompeians edible” | One ornate simile doing three jobs |
| Semicolon cascade + long Sextilius paren in one block | Multi-clause AI cadence |
| “as if furniture had spoken out of turn” | Ledger/furniture cleverness |
| “Rain, cousins, a mule…” catalogue as one sculpted line | Catalog wit stamp |
| “foreign furniture” / “child’s schedule” stack | Content-word density + ops dialect |
| Parenthetical smaller-ask | Aside that lengthened without adding life |
| “forgiven into irrelevance. It is a delicate art.” | Aphorism stack; kept first clause only |
| “as if by accident” / “pricing something” / “station warning” | Hedged / ledger polish |

| Kept on purpose | Why |
|-----------------|-----|
| “Cassius ate.” / “Cassius walked.” | Human short beats; not the problem |
| Soft chain + digest exchange | Load-bearing brand |
| “That is a skill.” | Character-true, earned once |
| Host “draft under the door” *as if* | One remaining courtesy simile; room still needs it |

## Sample before → after

**Before:**  
The host toasted Caesar’s clemency as if mercy were a spice that made leftover Pompeians edible. Thapsus was finished; Cato had become other men’s sermons; triumph dust still stuck to the city’s shoes.

**After:**  
The host toasted Caesar’s clemency. Mercy made leftover Pompeians sound edible. Thapsus was finished. Cato had become other men’s sermons. Triumph dust still stuck to the city’s shoes.

**Before:**  
Sextilius: “…keeps a child’s schedule under Caesar’s roof. Private hours with foreign furniture. Fresh enough that the paint still smells.”

**After:**  
Sextilius: “…keeps a child under Caesar’s roof. Private hours. Fresh paint. Best not to notice aloud.”
