# Archive — Development History

**Status:** Historical / completed. Not current canon.

This directory holds superseded plans, finished pass logs, and editorial reports from Book 1 development. Preserve them for institutional memory; do not treat them as instructions for what to do next.

Live authority lives elsewhere — see the [root README](../README.md) and [docs/INDEX.md](../docs/INDEX.md).

## Layout

| Folder | Contents |
|--------|----------|
| [`pass_logs/`](pass_logs/) | Completed prose/craft passes and screening logs |
| [`plans/`](plans/) | Finished phase plans and drafting-start decisions |
| [`reports/`](reports/) | Editorial diagnoses, audits, cold-read packets, evaluations |

## Classification principle

A document was moved here when it **no longer governs current work**: the pass is done, the phase is complete, or the diagnosis has been superseded by later work and by the manuscript itself.

Kept in active trees (not archived):

- `continuity/canon.md`, `unresolved_questions.md`, `contradictions.md`, `future_research.md`, `lock_architecture_audit.md`
- `continuity/character_profiles/`, `continuity/expansion/` (live architecture summaries)
- All of `drafts/`, `story/`, `research/`, `writing/`

## How to use

1. Prefer the manuscript and current canon when deciding story facts.
2. Open an archive file when you need *why* a structure or ambiguity exists.
3. Do not resume a completed phase plan as if it were the next task.
4. Meaningful disagreements and reversals inside these files are intentional history — not errors to “clean up.”
