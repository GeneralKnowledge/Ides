## Fog rules (use these instead of numbers)

1. **No narrator body-count.** POVs hear “thousands,” “the legion,” “the camp taken” — contradictory.  
2. **Cassius’ death is an INF failure:** messenger late, dust wrong, friend misreports, signal misread. Theme > tactics.  
3. **Brutus after Cassius:** grief + philosophical bracing; not instant collapse into one speech.  
4. **F3 / soldiers:** mud, thirst, pay promises, which eagle still stands — not Senate ideology.  
5. **F4 / money men:** land assignments rumoured before corpses cool (SC-89 seed).  
6. **Optional F5:** Eastern extraction victims hear Philippi as tax weather changing — distant.

## Working geography (B, schematic)

- Plain near Philippi / Via Egnatia corridor.  
- Camps, marshes, and hills matter as **obstacles to sightlines** (why Cassius can be wrong).  
- Do not invent modern GPS place-names; one hill / one marsh / one camp ditch is enough.
