# Names across both books

**Rule:** one handle, one person, for the reader, across the whole series. A handle is the name the narration uses for someone. Before a new person gets a handle, check this file; `python3 tools/book2_names_check.py` fails if a handle appears twice.

The **Near** column flags handles that are not identical but close enough to confuse a reader; the scene must make clear who is meant.
