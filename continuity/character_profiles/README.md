# Character Profiles — Consistency Toolkit

**Purpose:** Check whether on-page behaviour matches who each person is — not to invent new biographies.

**Authority order when sources conflict**

1. Current chapter prose in `drafts/book1/`
2. Locked canon (`continuity/canon.md`, `story/pov_lock.md`)
3. These profiles (derived from 1–2 + `writing/voice/POV_DICTION.md` + F-dossiers)
4. Older planning notes

**How to use on a cold read or audit**

For any scene, ask:

1. Does this action serve a want this profile names?
2. Would this person notice *this* detail (occupation / class / fear)?
3. Are they acting only on information they can possess now?
4. Is the humour / silence register right for them?
5. Does anything violate a **Must not** lock?

Mark findings as **problem** (contradicts profile + text) or **preference** (you want a different characterisation — requires author approval before changing canon).

**Do not** use profiles to force every character into equal cleverness, equal dialogue share, or equal cynicism.
