# Names new in Book 0

**Rule:** one handle, one person, across the whole series. The carried cast and everything Books 1 and 2 already use are in [book2/canon/names.md](../../book2/canon/names.md); this file lists only handles Book 0 adds. `python3 tools/book0_names_check.py` fails if a handle here repeats, or is already a handle in Book 2's list.

Book 0 invents no new named people in storyboard v1. Every new handle below is a real person. Household and ranks stay unnamed unless a scene needs a name, and then the name comes here first with a reason.
